# Water Distribution System Modeling Toolkit

**[Open the live dashboard](https://waterdistributionmodelling-3vxrlujndnj5qghabqy3br.streamlit.app/)**: network maps, a pump curve explorer, fire flow lookup, and the assumptions table. The hosted app may take about 30 seconds to wake up.

## 1. Summary

This project builds pressurized-pipe hydraulics from first principles and applies them in a master-plan-style study of a benchmark distribution system. The built layer validates pipe head loss, pump and system curves, and a steady-state network solver. That solver reproduces EPANET 2.2 to within 0.14 mm of head on every test network. The engineering layer uses EPA's WNTR package to run six analyses on EPANET's Net3 network: baseline extended-period compliance, available fire flow, a greedy pipe-sizing heuristic, water age, pump energy cost under a time-of-use tariff, and pipe criticality. Every result traces to a governing equation, a stated assumption in [`data/assumptions.yaml`](data/assumptions.yaml), or a validation check in the test suite (255 tests, 99% line coverage). Everything shown here is regenerated by one command (Section 6).

## 2. Governing equations

Internal calculations use SI units; reports use US customary units. All conversion factors are exact definitions in [`units.py`](src/wdtk/units.py).

**Hazen-Williams.** The defining velocity form, with the constants verified against Bombardelli and García (2003), is

$$V = k \cdot C \cdot R^{0.63} \cdot S^{0.54},\qquad k = 1.318\ \text{(ft-s)},\quad k_{SI} = 1.318\cdot0.3048^{0.37} = 0.8492 .$$

With $R = D/4$ and $S = h_f/L$, this gives $h_f = \frac{10.67 \cdot L \cdot Q^{1.852}}{C^{1.852} \cdot D^{4.870}}$ in SI. EPANET rounds the constants to $10.6668 \cdot C^{-1.852} \cdot D^{-4.871} \cdot L \cdot Q^{1.852}$, which gives 0.05–0.10% less head loss. Both forms are implemented (`convention="exact"` or `"epanet"`). The network solver uses the EPANET form so the two can be compared directly.

**Darcy-Weisbach.** $h_f = f \cdot \left(\frac{L}{D}\right) \cdot \left(\frac{V\lvert V\rvert}{2g}\right)$ with:
- laminar flow, $f = 64/\mathrm{Re}$, for Re ≤ 2,000;
- Colebrook-White, $1/\sqrt f = -2\log_{10}\!\big(\tfrac{\varepsilon/D}{3.7} + \tfrac{2.51}{\mathrm{Re}\sqrt f}\big)$, solved with Brent's method, or Swamee-Jain, $f = 0.25/\log_{10}^2\!\big(\tfrac{\varepsilon/D}{3.7} + \tfrac{5.74}{\mathrm{Re}^{0.9}}\big)$, for Re ≥ 4,000;
- linear interpolation between those limits. That interpolation is a stated modeling assumption, not physics.

Minor losses are $h_m = \sum K\,V\lvert V\rvert/2g$.

**Pumps.** Head curves have the form $H = a - bQ^c$:
- A single design point gives $a = \tfrac43 H_d$, $b = H_d/(3Q_d^2)$, $c = 2$.
- Three points give an exact fit. These conventions were read from WNTR's EPANET-replicating source code.
- At speed ratio $s$, the affinity laws give $a' = s^2a$ and $b' = s^{2-c}b$.
- Power is $P = \rho g Q H/\eta$.
- NPSH available is $\mathrm{NPSH_a} = (p_{atm}-p_v)/\rho g + z_s - h_{f,s}$.

**Network solver.** The global gradient algorithm of Todini and Pilati (1987), as used by EPANET. With the link-node incidence matrices $A_{12}$ and $A_{10}$, steady state requires

$$h(Q) + A_{12}H + A_{10}H_0 = 0,\qquad A_{21}Q = q,\qquad A_{21} = A_{12}^T .$$

Newton's method with $D = \mathrm{diag}(\partial h/\partial Q)$, after eliminating $\Delta Q$, leaves a sparse symmetric positive-definite system for the heads:

$$(A_{21}D^{-1}A_{12})\,\Delta H = F_2 - A_{21}D^{-1}F_1,\qquad \Delta Q = -D^{-1}(F_1 + A_{12}\Delta H).$$

The derivation is worked through in [`notebooks/02_gga_formulation.ipynb`](notebooks/02_gga_formulation.ipynb). A Hardy Cross loop-correction solver is included for comparison.

## 3. Validation

**Pipe hydraulics** is checked by property-based tests:
- Hazen-Williams SI and US forms agree to $10^{-12}$ after unit conversion.
- Every inverse function returns its original input to $10^{-9}$: diameter for a target head loss, flow capacity for an available head, and back-calculated C.
- Swamee-Jain stays within 2.83% of Colebrook over Re 5,000 to 10⁸ and ε/D 10⁻⁶ to 10⁻². The worst case is the corner Re = 5,000, ε/D = 0.01, and only 7.6% of that range exceeds 1% ([`reports/phase1/swamee_jain_accuracy.csv`](reports/phase1/swamee_jain_accuracy.csv)).

With C fitted so the two formulas agree at 300 mm and 1 m/s, they diverge elsewhere. Hazen-Williams predicts 20% less head loss than Darcy-Weisbach for small, fast pipes and 10% more for large, slow ones. The C that would match Darcy-Weisbach varies with velocity, diameter and roughness, so C is not a constant of the pipe. That's why Darcy-Weisbach is the right choice outside the conditions where a C-factor was calibrated.

![Hazen-Williams / Darcy-Weisbach head loss ratio](reports/phase1/hw_dw_headloss_ratio.png)
![Equivalent Hazen-Williams C](reports/phase1/equivalent_c_factor.png)

**Pumps against EPANET** The model is a single pump and pipe between two reservoirs; the acceptance tolerance is 0.5% ([`reports/phase2/pump_validation_epanet.csv`](reports/phase2/pump_validation_epanet.csv)).

| Case | Flow, wdtk (L/s) | Flow, EPANET (L/s) | Δ flow | Head, wdtk (m) | Head, EPANET (m) | Δ head |
|---|---|---|---|---|---|---|
| Single-point curve | 108.042 | 108.057 | −0.014% | 47.212 | 47.206 | +0.011% |
| Three-point curve | 100.158 | 100.174 | −0.016% | 44.958 | 44.954 | +0.009% |
| Three-point, 90% speed | 77.399 | 77.412 | −0.017% | 39.280 | 39.278 | +0.007% |
| Three-point, 80% speed | 50.222 | 50.231 | −0.019% | 34.166 | 34.165 | +0.004% |

The reduced-speed rows confirm that the affinity-law curve scaling reproduces EPANET's speed setting.

![Pump and system curves at variable speed](reports/phase2/pump_system_vfd.png)

**Network solver against EPANET** The test networks are a single loop, a two-loop grid, and EPANETs Net1 reduced to steady state, each in Hazen-Williams form, plus the two looped networks in Darcy-Weisbach form. The solver and EPANET read the same `.inp` file. Acceptance: heads within 0.01 m; flows within 0.1% or 0.001 L/s ([`reports/phase3/`](reports/phase3/)).

| Network | Max head difference (m) | Max flow difference (L/s) | Max relative flow difference | GGA iterations | Hardy Cross sweeps |
|---|---|---|---|---|---|
| Single loop, H-W | 5.9×10⁻⁵ | 2.8×10⁻⁶ | 6.9×10⁻⁸ | 5 | 5 |
| Two loop, H-W | 1.4×10⁻⁴ | 1.1×10⁻⁵ | 1.3×10⁻⁷ | 4 | 19 |
| Net1 (steady), H-W | 9.9×10⁻⁵ | 2.2×10⁻⁵ | 3.9×10⁻⁷ | 5 | n/a (has a pump) |
| Single loop, D-W | 4.5×10⁻⁵ | 7.7×10⁻⁶ | 1.5×10⁻⁷ | 7 | 7 |
| Two loop, D-W | 1.0×10⁻⁴ | 8.3×10⁻⁶ | 2.0×10⁻⁷ | 5 | 21 |

All 68 heads and flows pass. Hardy Cross converges to the same solution as GGA, agreeing to $10^{-8}$ m. GGA converges quadratically on Hazen-Williams networks. On Darcy-Weisbach networks it converges linearly, because the friction factor is held fixed within each iteration.

## 4. Design study results: EPANET Net3

Net3 has 92 junctions, 3 tanks, 2 supply reservoirs, 117 pipes (8–99 in), and 2 pumps. Analyses run on EPANET 2.2 through WNTR, with pressure-dependent demand where flow can be cut short. Results are in [`reports/phase4/`](reports/phase4/); every criterion is in Section 5.

**4a Baseline (72-hour extended-period simulation).**
- All 59 demand junctions stay between 38.7 and 75.5 psi, inside the 35–100 psi service range.
- Three pipes exceed the 5 ft/s velocity criterion: pipe 60 (24 in) at every reported hour, peaking at 9.4 ft/s, and pipes 125 and 329 (both 30 in) for 19 hours each, at about 6 ft/s.

![Minimum pressure](reports/phase4/4a_map_min_pressure.png)
![Tank levels](reports/phase4/4a_tank_levels.png)

**4b Fire flow.** The scenario is max-day demand at 20 psi residual, with 1,500 gpm required. Available flow is the largest flow that keeps both the hydrant junction and every other demand junction at or above the residual.
- 57 of 59 junctions meet the requirement.
- Junction 15 delivers 768 gpm, limited by its own residual pressure.
- Junction 143 delivers 1,020 gpm, limited by the residual at junction 15.

![Available fire flow](reports/phase4/4b_map_fire_flow.png)

**4c Recommended improvements.** A greedy heuristic upsizes, at each step, the pipe with the largest reduction in deficit per dollar. It is not a global optimum.

| Pipe | Length (ft) | Existing (in) | Proposed (in) | Planning cost |
|---|---|---|---|---|
| 149 | 1,400 | 8 | 16 | $546,000 |
| 151 | 1,650 | 8 | 16 | $643,500 |

The total is $1.19M including 30% contingency. After the change, both deficient junctions meet 1,500 gpm and no peak-hour pressure deficit remains. The velocity exceedances from 4a were outside the heuristic's targets.

![Recommended improvements](reports/phase4/4c_map_improvements.png)

**4d Water age (336-hour run, final 24 hours reported).**
- In the baseline, 20 of 59 demand junctions exceed the 72-hour concern threshold. The oldest junction is at 161 hours.
- Tank turnover is 2.9, 3.0 and 4.8 days for Tanks 1–3.
- The alternative tested moves pump 10's 14-hour run from 01:00 to 20:00. It reduces the count above threshold to 17, but makes water older overall: 33 junctions get older and 25 younger. Tank 2's maximum age rises from 163 to 230 hours, and Tank 3's turnover rises to 6.5 days.

![Water age](reports/phase4/4d_map_water_age.png)

**4e Pump energy (72 hours, time-of-use tariff).** The same off-peak shift of pump 10 raises energy cost by 45%, from $639 to $924, even though energy falls 3%, from 8,490 to 8,249 kWh.
- Pump 10's own cost falls from $227 to $187.
- But Tank 1 then draws down at different times, so pump 335, which is switched on Tank 1's level and draws about 310 kW, moves from 0% to 78% of its energy at on-peak prices. Its cost rises from $412 to $736.
- The alternative is hydraulically feasible: no new pressure or tank-level violations.

The obvious operational change fails on both cost and water quality.

![Pump power, baseline vs alternative](reports/phase4/4e_pump_power.png)

**4f Criticality.** Each of 87 pipes of 12 in and larger was closed for 24 hours under pressure-dependent demand. Pipe 330 was excluded because a control could reopen it during the run.
- Two short 24-inch pipes dominate: closing pipe 233 leaves 41% of daily demand unserved, and closing pipe 193 leaves 16%.
- Pipes 229 and 189 each leave 3.5% unserved but drop 21 junctions below the minimum service pressure.
- Every other screened pipe is under 2%.

These four pipes are the first candidates for redundancy or condition assessment.

![Pipe criticality](reports/phase4/4f_map_criticality.png)

## 5. Assumptions and limitations

Every assumption is in [`data/assumptions.yaml`](data/assumptions.yaml), with its value, units, the source, and a status. All values are for demonstration, not design, and the study refuses to run while any is marked draft.

| Group | Values (status) |
|---|---|
| Service criteria | 35–100 psi; 5 ft/s maximum velocity (approved) |
| Pressure-dependent demand | No delivery at 0 psi, full delivery at 20 psi (approved) |
| Demand | Max-day factor 1.5 (approved); peak hour taken from Net3's patterns (network) |
| Fire flow | 1,500 gpm at 20 psi residual; every demand junction is a hydrant location; max-day steady state with tanks at initial levels (approved) |
| Sizing | Ductile iron sizes 6–60 in; $150–1,300 per ft, illustrative; 30% contingency (approved) |
| Water age | Concern above 72 h; 336-hour run; pump 10 start moved to 20:00 (approved) |
| Energy | $0.15/kWh from 12:00 to 20:00, $0.07/kWh otherwise (approved); 75% pump efficiency (network) |
| Criticality | Pipes 12 in and larger, 24-hour outage (approved) |
| Pumps | Atmospheric pressure 14.4 psi (Chicago area); NPSHa/NPSHr margin 1.0–1.3 (supplied by the project author) |

**Sources.**
- Water properties come from a table supplied by the project author, citing J. Phys. Chem. Ref. Data 7, 941 (1978), and are interpolated with cubic splines between 0 and 40 °C.
- Hazen-Williams constants and the Reynolds number limits follow Bombardelli, F. A., and García, M. H. (2003), "Hydraulic Design of Large-Diameter Pipes," *J. Hydraul. Eng.* 129(11), 839–846.
- EPANET's conventions were read from WNTR 1.5.0's source code or measured, as described in Section 3. They were not recalled from memory.

**Limitations.**
- **Costs:** unit costs are illustrative and planning-level only.
- **Fire flow:** treating every demand junction as a hydrant, at the network's starting tank and pump state, is a simplification.
- **Sizing:** the heuristic makes one greedy choice at a time and never revisits it, so a cheaper set of improvements may exist. It doesn't target velocity.
- **Operational alternative:** the pump 10 schedule change was tested, not optimized. Adjusting pump 335's level controls at the same time might change the outcome.

## 6. How to run

Requires [uv](https://docs.astral.sh/uv/).

```
uv sync
uv run python scripts/reproduce_all.py
```

This regenerates every figure and table referenced above in a few seconds, plus `reports/key_results.json`.

Other commands:

```
uv run streamlit run app/streamlit_app.py   # project overview and interactive dashboard
uv run pytest                               # 255 tests, coverage report
uv run ruff check; uv run mypy              # lint and strict type check
```

The dashboard ([hosted version](https://waterdistributionmodelling-3vxrlujndnj5qghabqy3br.streamlit.app/)) offers:
- network maps colored by pressure, velocity, water age, or criticality;
- a pump curve explorer with a speed slider;
- a fire flow lookup by junction;
- the assumptions table.

Library code is in [`src/wdtk/`](src/wdtk/), test networks are in [`data/networks/`](data/networks/) (sources recorded in their README), and exploration notebooks are in [`notebooks/`](notebooks/).
