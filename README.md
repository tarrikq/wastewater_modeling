# Water Distribution System Modeling Toolkit (`wdtk`)

Pressurized water distribution hydraulics built from first principles and validated against
EPA EPANET (via WNTR), plus a master-plan-style design and resilience study on EPANET's Net3.

> Work in progress. The full technical write-up is a Phase 5 deliverable; see `PLAN.md`.
